WorldBuilder 2 not found

The editor uses your own copy of LEGO WorldBuilder 2 for its pictures, levels and to play your levels. It isn't included, so tell the editor where it is.

Looking for the game…

Option 1: put the game next to the editor

Copy your WorldBuilder2 folder into the editor's folder, so that this file exists:

…\WorldBuilder2\worldbuilder2\worldbuilder2.dcr

Then

Option 2: point to where the game is

Paste the full path of your WorldBuilder 2 folder (tip: in Explorer, Shift + right-click the folder and choose Copy as path).

This is saved in settings.json, which you can also edit by hand:

{
  "worldBuilder2": "D:/Games/WorldBuilder2",
  "worldBuilder1": "D:/Games/WorldBuilder"
}

worldBuilder1 is optional: the original LEGO WorldBuilder adds the scorpion and T-Rex animations and its 60 missions as templates. Without a setting, a WorldBuilder folder next to WorldBuilder2 is used if it's there.
